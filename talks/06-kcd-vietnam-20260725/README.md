# KCD Vietnam 2026 - From Project to Production: HAMi and Viettel Cloud

**Date:** July 25, 2026
**Event:** KCD & OpenInfra Days Vietnam 2026 (VietOpenInfra), Sheraton Hanoi Hotel, Hanoi, Vietnam
**Speakers:** Reza Jelveh - HAMi; The Anh Nguyen

## Topic

Kubernetes treats GPUs as atomic resources, leading to over-provisioning and low utilization in multi-tenant AI Notebook environments. HAMi's vGPU virtualization together with DRA solves this - if implemented correctly.

- GPU sharing mechanisms: DRA resource requests, fine-grained HAMi GPU allocation, memory isolation, compute slicing
- Viettel Cloud production deployment: architecture and key bottlenecks from testing to production
- Operational practices for fine-grained GPU sharing in telecom-grade data science workloads
