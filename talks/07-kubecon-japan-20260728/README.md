# KubeCon + CloudNativeCon Japan 2026 - Shared GPU Scheduling & Proactive Autoscaling

**Date:** July 28-30, 2026
**Event:** KubeCon + CloudNativeCon Japan 2026, Pacifico Yokohama, Yokohama, Japan
**Speakers:** Jeonghyun Kim; Reza Jelveh - HAMi

## Topic

Orchestrating GPU workloads on Kubernetes with HAMi, featuring the SNOW Corporation production case study:

- Shared GPU scheduling with HAMi in multi-tenant Kubernetes clusters
- Proactive autoscaling of GPU inference workloads
- Lessons from the SNOW Corp production deployment (CNCF case study)
