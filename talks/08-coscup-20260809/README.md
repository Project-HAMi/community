# COSCUP 2026 - Running Multiple AI Workloads on One GPU with HAMi

**Date:** August 9, 2026, 11:20-11:50
**Event:** COSCUP x UbuCon Asia 2026 (Golang TW x Cloud Native track, Room TR214), Taipei, Taiwan
**Speaker:** Reza Jelveh - HAMi

## Topic

GPUs are expensive. Kubernetes cannot share them well yet, and DRA is still in development. HAMi brings heterogeneous GPU sharing to Kubernetes.

- How HAMi intercepts CUDA calls without application code changes
- Why memory isolation matters, and how HAMi enforces it
- Real production case: teams cutting GPU costs by 40-60%
