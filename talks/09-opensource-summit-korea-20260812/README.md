# Open Source Summit Korea 2026 - Simplifying AI for Edge Compute with HAMi

**Date:** August 12, 2026, 11:40-12:10 KST
**Event:** Open Source Summit Korea 2026, InterContinental Grand Seoul Parnas, Seoul, South Korea
**Speaker:** Reza Jelveh - HAMi

## Topic

Open-source agents can reason and use tools, but running them at the edge is still hard - the problem is not the model, it is the compute layer underneath: limited memory, tight power budgets, no ops team.

- Edge GPU and memory slicing: splitting a device's unified memory so multiple agents run concurrently on hardware as small as an NVIDIA Jetson, with time-sharing under memory pressure
- Jetson-class GPUs vs NPUs from Axelera and DeepX - better performance per watt, and what it takes to make them schedulable
- HAMi as the hardware-agnostic GPU virtualization layer: one scheduling plane across heterogeneous accelerators, fine-grained memory slicing, open source
