# Observability Summit Europe 2026 - Vendor-Neutral GPU Observability for Kubernetes

**Date:** October 5, 2026, 16:25-16:50 CEST
**Event:** Observability Summit Europe 2026, Prague Congress Centre (South Hall 3 B), Prague, Czechia
**Speaker:** Reza Jelveh - HAMi

## Topic

GPU observability in Kubernetes is fragmented. Every vendor ships its own metrics stack: NVIDIA DCGM, AMD ROCm SMI. Platform teams running heterogeneous clusters stitch together three different dashboards to answer one question: are my GPUs being used efficiently?

- HAMi (CNCF Incubating) sits at the scheduling layer and sees every GPU operation - a single integration point for centralized observability
- Consistent metrics across NVIDIA, AMD, Ascend and any accelerator with a device plugin
- Getting vendor-neutral utilization and allocation signals without deploying three separate agents
