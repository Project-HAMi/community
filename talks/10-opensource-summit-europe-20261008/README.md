# Open Source Summit Europe 2026 - Designing Permissioned AI Agents That Can Run Offline

**Date:** October 8, 2026, 14:40-15:20 CEST
**Event:** Open Source Summit Europe 2026, Prague Congress Centre (Forum Hall), Prague, Czechia
**Speaker:** Reza Jelveh - HAMi

## Topic

AI agents are moving from chat interfaces to real workflows: reading files, calling tools, mutating state and orchestrating services. Cloud-hosted designs create fragile trust boundaries: private data leaves the device, tools are authorized via over-privileged API keys, and users cannot see what the agent can actually do.

- An open-source, local-first, permission-gated AI agent design that runs offline on Linux edge devices or personal infrastructure
- Core premise: every tool is untrusted, so limits must be enforced at the tool side, not left to agent discretion
- Decomposing the boundary into tool invocation, deny-by-default capabilities, and auditable permission grants
